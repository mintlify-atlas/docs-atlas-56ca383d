---
title: "Install MCLI on Windows, macOS, and Linux"
sidebarTitle: "Installation"
description: "Install MCLI via a prebuilt binary, pip from source, a native Linux package (.deb, .rpm, Arch), or the Nix flake for NixOS and macOS."
---

MCLI can be installed in several ways depending on your platform and preferences. Prebuilt binaries bundle Python and all dependencies into a single executable — no Python installation required. If you prefer to work from source, you need Python 3.10 or newer. Native Linux packages (.deb, .rpm, and Arch) are generated by the same CI workflow and install `mcli` to `/usr/bin`. NixOS and nix-on-macOS users can build directly from the included `flake.nix`.

<Tabs>
  <Tab title="Prebuilt Binary">
    Standalone executables are attached to every GitHub Release and to every CI run under **Actions → Build MCLI binaries**. Download the archive for your platform, extract it, and run `mcli`.

    **Primary targets**

    | Platform | Artifact |
    |---|---|
    | Windows x64 | `mcli-windows-x64.zip` |
    | Windows ARM64 | `mcli-windows-arm64.zip` |
    | Linux x64 | `mcli-linux-x64.tar.gz` |
    | Linux ARM64 | `mcli-linux-arm64.tar.gz` |
    | macOS Intel (x86\_64) | `mcli-macos-intel.tar.gz` |
    | macOS Apple Silicon (ARM64) | `mcli-macos-arm64.tar.gz` |

    **Experimental targets**

    The CI matrix also produces artifacts for a long-tail set of architectures. These prove the CLI can be packaged for each target but do not guarantee every Minecraft version will launch there (Minecraft/LWJGL native availability and Java runtime availability remain target-specific).

    | Platform | Notes |
    |---|---|
    | Windows x86 (32-bit) | Experimental |
    | Linux x86 (32-bit) | Experimental |
    | Linux ARMv7 | Experimental |
    | Linux RISC-V 64 (`riscv64`) | Experimental |
    | Linux PowerPC 64 LE (`ppc64le`) | Experimental |
    | Linux IBM Z (`s390x`) | Experimental |
    | FreeBSD x86\_64 | Experimental — native VM build |
    | FreeBSD ARM64 | Experimental — native VM build |
    | OpenBSD x86\_64 | Experimental — native VM build |
    | OpenBSD ARM64 | Experimental — native VM build |
    | NetBSD x86\_64 | Experimental — native VM build |
    | NetBSD ARM64 | Experimental — native VM build |

    **Extract and run (macOS / Linux)**

    ```bash
    tar -xzf mcli-linux-x64.tar.gz
    chmod +x mcli
    ./mcli --help
    ```

    **Extract and run (Windows)**

    ```powershell
    Expand-Archive mcli-windows-x64.zip -DestinationPath mcli-windows-x64
    .\mcli-windows-x64\mcli.exe --help
    ```

    Optionally move the `mcli` (or `mcli.exe`) binary to a directory on your `PATH` so you can invoke it from anywhere.

    <Note>
      The prebuilt binary bundles Python and all Python dependencies. You do **not** need to install Python separately. Minecraft's required Java runtimes continue to be managed separately by MCLI at runtime.
    </Note>
  </Tab>

  <Tab title="From Source">
    Building from source gives you the latest code and makes it easy to contribute. You need **Python 3.10 or newer**, `pip`, and `git`.

    <Steps>
      <Step title="Clone the repository">
        ```bash
        git clone https://github.com/Hampter588/MCLI.git
        cd MCLI
        ```
      </Step>
      <Step title="Install in editable mode">
        ```bash
        python -m pip install -e .
        ```
        This installs the `mcli` entry-point and the single runtime dependency (`requests>=2.31`) into your current Python environment.
      </Step>
      <Step title="Verify the installation">
        ```bash
        mcli --help
        ```
        You should see the MCLI command listing with all available subcommands.
      </Step>
    </Steps>

    **Requirements summary**

    | Requirement | Version |
    |---|---|
    | Python | 3.10 or newer |
    | pip | any recent version |
    | git | any recent version |
  </Tab>

  <Tab title="Linux Packages">
    Native packages install `mcli` to `/usr/bin` and integrate with your distribution's package manager. Download the appropriate package from GitHub Releases.

    ### Debian / Ubuntu (.deb)

    Packages are built for **amd64** and **arm64**.

    <Steps>
      <Step title="Download the .deb for your architecture">
        ```bash
        # amd64
        wget https://github.com/Hampter588/MCLI/releases/latest/download/mcli_amd64.deb

        # arm64
        wget https://github.com/Hampter588/MCLI/releases/latest/download/mcli_arm64.deb
        ```
      </Step>
      <Step title="Install with dpkg">
        ```bash
        sudo dpkg -i mcli_amd64.deb
        ```
      </Step>
      <Step title="Verify">
        ```bash
        mcli --help
        ```
      </Step>
    </Steps>

    ### Fedora / RHEL-family (.rpm)

    Packages are built for **x86\_64** and **aarch64**.

    <Steps>
      <Step title="Download the .rpm for your architecture">
        ```bash
        # x86_64
        wget https://github.com/Hampter588/MCLI/releases/latest/download/mcli_x86_64.rpm

        # aarch64
        wget https://github.com/Hampter588/MCLI/releases/latest/download/mcli_aarch64.rpm
        ```
      </Step>
      <Step title="Install with rpm or dnf">
        ```bash
        sudo rpm -i mcli_x86_64.rpm
        # or
        sudo dnf install ./mcli_x86_64.rpm
        ```
      </Step>
      <Step title="Verify">
        ```bash
        mcli --help
        ```
      </Step>
    </Steps>

    ### Arch Linux (PKGBUILD)

    A `PKGBUILD` is provided in `packaging/arch/PKGBUILD` for **x86\_64** and **aarch64**. It installs a pre-built binary to `/usr/bin/mcli`.

    <Steps>
      <Step title="Download the PKGBUILD and a binary artifact">
        Clone the repository or download `packaging/arch/PKGBUILD`. Place the matching `mcli` binary in the same directory as the PKGBUILD.
      </Step>
      <Step title="Build and install the package">
        ```bash
        makepkg -si
        ```
      </Step>
      <Step title="Verify">
        ```bash
        mcli --help
        ```
      </Step>
    </Steps>

    <Warning>
      The Arch PKGBUILD contains a repository placeholder (`OWNER/REPO`) that must be replaced with the actual GitHub repository URL before use.
    </Warning>
  </Tab>

  <Tab title="Nix">
    MCLI ships a `flake.nix` that supports four systems:

    - `x86_64-linux`
    - `aarch64-linux`
    - `x86_64-darwin`
    - `aarch64-darwin`

    **Build the package**

    ```bash
    nix build
    ```

    The result is available at `./result/bin/mcli`.

    **Run without installing**

    ```bash
    nix run
    ```

    **Add to your NixOS or home-manager configuration**

    Reference the flake directly from your configuration inputs:

    ```nix
    inputs.mcli.url = "github:Hampter588/MCLI";
    ```

    Then include `inputs.mcli.packages.${system}.default` in your `environment.systemPackages` or `home.packages`.
  </Tab>
</Tabs>
