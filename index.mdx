## What MCLI Does

MCLI replaces the official Minecraft launcher for developers and power users who prefer the command line. It manages the full lifecycle of Minecraft clients and servers without a graphical interface.

## Get Started in Minutes

<Steps>
  <Step title="Install MCLI">
    Download a prebuilt binary from GitHub Releases or install from source with pip:
    ```bash
    python -m pip install -e .
    ```
  </Step>
  <Step title="Log in with Microsoft">
    Authenticate your Microsoft account so MCLI can launch authenticated Minecraft sessions:
    ```bash
    mcli login
    ```
  </Step>
  <Step title="Launch Minecraft">
    Pick a version and launch. MCLI installs Java and downloads game files automatically:
    ```bash
    mcli release 1.21.1
    ```
  </Step>
  <Step title="Explore Further">
    Create isolated instances, install modloaders, manage mods, and run servers — all from the same CLI.
    ```bash
    mcli instance create survival release 1.21.1
    mcli release 1.21.1 --fabric
    mcli mods install sodium --instance survival --loader fabric
    ```
  </Step>
</Steps>
