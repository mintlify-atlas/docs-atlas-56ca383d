MCLI is an open-source, command-line Minecraft launcher written in Python. Where graphical launchers bury options behind menus, MCLI exposes the full launcher surface through a single `mcli` command — letting you log in with a Microsoft account, browse and launch any Minecraft version (including historical builds sourced from Omniarchive), manage isolated instances, install Fabric, Forge, NeoForge, or Quilt, search Modrinth for mods and modpacks, and spin up dedicated servers, all without leaving your terminal.

## Project Status

MCLI 1.0 ships the complete launcher architecture — accounts, Java management, instances, modloaders, Modrinth integration, and servers are all functional. It should still be treated as an early project until launch paths have been extensively tested across the full matrix of Minecraft versions, operating systems, Java runtimes, and modloader combinations. Historical builds in particular can require version-specific compatibility work.

Items on the active roadmap include:

- CurseForge integration
- Mod updates and compatibility management
- Import from Prism, MultiMC, or an existing `.minecraft` directory
- Download progress bars, automatic retries, and resume
- Crash diagnostics and `mcli doctor`
- Server console management and backups
- Stronger historical compatibility profiles
- Packaged Windows, macOS, and Linux releases
